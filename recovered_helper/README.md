# 内嵌辅助程序的 C 逻辑重建

这是从第一层数据中提取的 3,584 字节 x86 PE 的逻辑重建，**不是主程序“抢皮”功能的源码，也不是原作者的原始工程**。
函数名、变量名和代码组织由分析者重新命名。未恢复原始注释、工程配置或调试符号。

## 范围

- 原入口：0x401000；重建为 reconstructed_entry。
- 引号字段提取：0x40114d；copy_quoted。
- 比较至任一字符串结束：0x401177；compare_until_either_end。
- 保留非标准输入行为的整数解析：0x4011a9；parse_decimal_quirks。
- 不补写终止符的字符串追加：0x4011d7；append_without_terminator。

辅助程序从命令行中读取目标进程 ID、程序路径和可选参数，调用 TerminateProcess，等待后调用 CreateProcessA。该行为由导入表和入口反汇编支持。

## 验证

四个底层函数通过 17 组交叉核验：在受限 x86 CPU 仿真中运行原始函数，并与重建算法的参考实现比较。
包含了前缀比较返回相等、非数字解析及追加函数不补终止符等不寻常行为，未把这些行为擅自“修正”。
checks.json 保存核验输入和结果。

C 文件未编译，完整入口未运行；交叉核验验证的是相应算法，不是对整份 C 文件完成了二进制等价证明。
主程序保护层仍在单独分析，不应把本文件统计为已经恢复了业务源码。

## 注意

重建保留了原函数的无边界扫描和缓冲区写入习惯，不保证异常输入下安全，也未声称复现不同全局变量布局下的越界副作用。
入口会终止指定进程并启动另一个程序；本次分析未执行这些 Windows API，不建议直接编译运行此重建文件。
